# Borujerd House Price Prediction

A Python-based educational project developed as an undergraduate Computer Engineering project, focused on estimating residential property prices in Borujerd, Iran.

## Project Overview

This project explores house price estimation using property-related information and a Streamlit-based interactive interface.

It was developed as an undergraduate project for academic and learning purposes.

## Technologies Used

- Python
- Streamlit
- Pandas

## Project Structure

```text
Borujerd-House-Price-Prediction/
├── app.py
├── train_model.py
├── requirements.txt
└── README.md
```

## Installation

Clone the repository:

```bash
git clone https://github.com/MrKm81/Borujerd-House-Price-Prediction.git
cd Borujerd-House-Price-Prediction
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Running the Application

```bash
streamlit run app.py
```

Then open the local URL displayed in your terminal.

## Limitations

This is an educational prototype. Its price estimates should not be treated as verified real-estate valuations or used as the sole basis for financial decisions.
